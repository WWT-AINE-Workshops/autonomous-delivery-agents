The board treats every card the same. When the team is busy it is hard to tell what to pick up first.

**What we want**

Three priority levels: low, normal and high. New tasks start at normal. The card shows the level for high-priority tasks, and the API can set the level when a task is created and when it is updated.

**Acceptance criteria**

The criteria and the commands that check them are in the spec the labs work from, `specs/priority.md`, and in `specs/priority.acceptance.json`.
